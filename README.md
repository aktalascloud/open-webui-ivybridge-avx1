# Open WebUI AVX1

[Upstream](https://github.com/open-webui/open-webui) · [ZIP release](https://github.com/aktalascloud/open-webui-ivybridge-avx1/releases/latest) · [Applied patches](patches/README.md)

Windows fork for Ivy Bridge (AVX/F16C). Extract the ZIP and run `Install.cmd`. Source build: `Build.cmd status`, then `Build.cmd build` with Python 3.12+, Git and GitHub CLI. CI recipes and checks live in `.avx1/`. Models and weights are runtime inputs.

Русский интерфейс, интеграция Terminal, голос и VRM, Strata и FreeLLM. Анонимный каталог: Beam 501B и Nemotron Ultra 550B, общий лимит шлюза. Распакуйте ZIP, запустите `Install.cmd`. Данные и настройки храните отдельно от исходников.
