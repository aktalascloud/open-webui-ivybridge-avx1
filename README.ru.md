# Open WebUI · Ivy Bridge AVX1

Переключатель Strata в поле ввода: штатные уровни рассуждений, отдельные «Ультра» и «Адаптивный» на базе закреплённого MIT-селектора Mnemosyne. Для пар используется профиль рассуждений; дополнительный блок стиля ответа второй части не вставляется. Режимы доступны только для отмеченной DavidAU Qwen3.8-Next; Swift исключён. Обычные настройки остальных моделей сохранены; текст шаблона и общая память в пакет не входят.

[English](README.md) · [Русский](README.ru.md) · [Исходный проект](https://github.com/open-webui/open-webui) · [Релизы](https://github.com/aktalascloud/open-webui-ivybridge-avx1/releases/latest)

Сборка Windows для Ivy Bridge. Дополнены русский интерфейс и меню.

Скачайте последний ZIP, распакуйте и запустите `Install.cmd`.

## Изменения

Безопасность: уязвимая Authlib 1.7.2 заменена на 1.9.1; семь идентификаторов уязвимостей и точный набор проверок указаны в `.avx1/PATCHES.json`.

Upstream 0.12.5/dev: исправлены гонки загрузки чата [#33377](https://github.com/open-webui/open-webui/pull/33377), увеличен штатный предел итераций инструментов [#33384](https://github.com/open-webui/open-webui/pull/33384), уменьшены ответы изменений КБ [#33335](https://github.com/open-webui/open-webui/pull/33335), исправлен список OpenAPI-инструментов [#33205](https://github.com/open-webui/open-webui/pull/33205). Сохранены изоляция MCP и браузерного моста, добавлены 18 русских строк. MCP Apps выполняются в изолированном iframe; вызовы инструментов требуют подтверждения.

- Свежий upstream: MCP 2026-07-28 [#33087](https://github.com/open-webui/open-webui/pull/33087), стабильный порядок схем инструментов [#33000](https://github.com/open-webui/open-webui/pull/33000), пакетная проверка владельцев чатов [#32888](https://github.com/open-webui/open-webui/pull/32888). Реальные SDK-тесты проверяют новый и прежний HTTP-протоколы.
- Аргументы MCP со схемами альтернатив: [#32903](https://github.com/open-webui/open-webui/pull/32903); читаемые ошибки: [#32942](https://github.com/open-webui/open-webui/pull/32942).
- Серверная проверка прав на публикацию: [#32991](https://github.com/open-webui/open-webui/pull/32991), с сохранением позиционного аргумента БД.
- Совместимость фильтра/бриджа, микрофон, ограниченная озвучка и проверка готового интерфейса Chromium. [Все патчи](.avx1/PATCHES.json).

## Проверки и замеры

Проверены четыре профиля `ivybridge`: SSE4.2/AVX/F16C/POPCNT, O2/O3, Fat/ThinLTO и codegen units 1/8. AVX2/FMA/PGO/fast-math отключены. Лучший общий результат JSON: **+0,40%**, но сериализация схем инструментов медленнее на **5,42%**. По умолчанию сохранён обычный `orjson`. Все 23 проверки совместимости совпали. Это CPU-тесты JSON, не tokens/s LLM. [Исходные замеры и флаги](.avx1/measurements/ivy-flags-20261024.json).

Запрос метаданных КБ на этом ЦП: **на 94,76% меньше процессорных циклов**, медиана **94,1 → 4,96 мс**. Синтетическая SQLite в памяти: 160 файлов × 128 КиБ извлечённого текста; загрузка полного текста 20 МиБ → 0. Это только SQL/DTO, не tokens/s LLM. [Исходные замеры и точные методы](.avx1/measurements/kb-projection-20261029.json).

[Профиль оборудования](.avx1/hardware-profile.json): установленный PyTorch 2.14 собран для ЦП. Отдельный профиль исходной сборки использует CUDA 12.9 и `sm_61`; готовый wheel от этих переменных не пересобирается.

Оригинальные лицензии, уведомления и история исходников сохранены. Точные исходники указаны в релизе. Ключи, логи, модели LLM и закрытый код фильтра/бриджа в публичные пакеты не входят.
