# Open WebUI AVX1

[English](README.md)

Неофициальный форк: проверенные исправления для агентов/MCP и дополненный русский интерфейс. Один актуальный ZIP + Install.cmd.

[Upstream](https://github.com/open-webui/open-webui) · [Release](https://github.com/aktalascloud/open-webui-ivybridge-avx1/releases/latest) · [Patches](.avx1/PATCHES.json)

Обновление official 0.13.0/dev: учёт токенов Responses, compaction с учётом кэша, OAuth/PKCE, Session-авторизация Terminal и ограничение чтения файлов. Сохранены наши политики моделей/инструментов, микрофон/озвучивание/VRM и управление Strata.

Новые карточки наследуют настроенный VRM; явный выбор сферы/своего файла и существующие карточки сохраняются. Общие инструкции храните в настройках аккаунта, отличающиеся — в карточках.

Обновления mainstream dev сохраняют адаптеры Responses, Strata и аватаров. Выбор subagent в карточке ограничен списком администратора и доступом пользователя; другая модель использует собственные параметры. Браузер Terminal привязан к исходной сессии/API-ключу с учётом отзыва и ограничений endpoints.

## Сборка

Нужны Python 3.12+, Git и GitHub CLI для CI. Сборка не зависит от модели, её весов или Codex.

```cmd
Build.cmd status
Build.cmd build
```

`build` проверяет чистоту опубликованного коммита и запускает закреплённый workflow. При готовом локальном компиляторе/SDK: `Build.cmd local`. Зависимости, флаги, тесты и проверки лицензий — в `.avx1/`. Lockfiles и история исходников сохранены. Ключи подписи в репозиторий не входят.

## Установка и проверки

Используйте единственный пакет релиза. Пользовательские данные храните отдельно от исходников. Адреса серверов и выбор моделей задаются настройками, а не требованиями сборки. Ivy Bridge: AVX/F16C, O3 и проверенный LTO, без AVX2/FMA/PGO/fast-math. Реальные флаги и prebuilt-компоненты указаны в манифесте.

Последние проверки и замеры: [.avx1/measurements/latest.json](.avx1/measurements/latest.json). Микрозамеры CPU не означают скорость LLM. Исходные лицензии и уведомления сохранены.

Замер на локальном CPU: запрос метаданных160 файлов KB больше не загружает20 МиБ извлечённого текста; медиана процессорных циклов ниже на94,63%. Это одна операция SQLite/Pydantic, а не скорость LLM. Исходные прогоны и хеши кода — в актуальном файле замеров.
